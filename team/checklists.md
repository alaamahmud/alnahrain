# قوائم "تم" — متى يُعتبر الشغل منتهياً

لا تقل "خلصت" قبل أن تمر على القائمة العامة + قائمة قسمك. إذا فشل بند، الشغل غير منتهٍ.

## القائمة العامة (للجميع)
- [ ] المهمة المطلوبة نُفذت كما طُلبت، لا أكثر ولا أقل.
- [ ] كل ملف ناتج محفوظ في الريبو ومذكور في التقرير.
- [ ] لا يوجد شيء نُشر أو أُرسل أو دُفع بدون موافقة صريحة من المالك.
- [ ] لا كلمات مرور ولا بيانات عملاء في أي ملف أو على اللوحة.
- [ ] التقرير الموحد مكتوب (أنجزت / الملفات / يحتاج المالك / عالق / التالي).
- [ ] اللوحة محدّثة: حالتي، المهمة، وحدث "أنهى".

## تكنولوجيا المعلومات
- [ ] أي فحص (موقع، دومين، SSL) مكتوب معه الوقت والنتيجة الفعلية، لا التوقع.
- [ ] أي تغيير على خادم أو إعداد = اقتراح مكتوب فقط حتى يوافق المالك.
- [ ] أدلة الدعم: خطوات مرقمة، تجرّبها خطوة خطوة، تذكر النظام (ويندوز/ماك/أندرويد/آيفون).
- [ ] الردود على العملاء = مسودات فقط.

## التطوير والحلول الذكية
- [ ] الكود يعمل محلياً (تشغيل أو اختبار) والناتج مذكور في التقرير.
- [ ] مختبرة الجودة راجعت التغيير قبل اعتباره منتهياً.
- [ ] لا مفاتيح API أو أسرار في الكود.
- [ ] الواجهة عربية RTL وتعمل على عرض الموبايل.
- [ ] مقترح الحل الذكي فيه: المشكلة، الحل، الكلفة التقريبية، الخطر، طريقة القياس.

## التسويق
- [ ] النص بالعربية السليمة، واضح، يذكر وحدة أو قطاع محدد.
- [ ] لا ادعاءات بأرقام غير موثقة (عدد عملاء، نسب توفير) إلا إذا أعطاها المالك.
- [ ] كل منشور أو إعلان = مسودة تنتظر موافقة المالك للنشر.
- [ ] عروض الأسعار: الأسعار من المالك فقط، لا تُخترع.
- [ ] معلومات التواصل الرسمية صحيحة (info@phi-iraq.org).
