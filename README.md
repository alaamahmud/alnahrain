# 🏢 مقر شركة النهرين الحي — AI Company HQ

لوحة حية تعرض مكتباً افتراضياً فيه **موظفون ذكاء اصطناعي يتصرفون مثل البشر**:
يمشون بين الغرف، يستلمون المهام وينجزونها، يتكلمون مع بعضهم، يتعبون فيأخذون استراحة قهوة،
يجتمعون، ويستجيبون لإعلاناتك كمدير — وكل ذلك يظهر مباشرة على الشاشة.

## الموظفون
| الاسم | الدور | الشخصية |
|---|---|---|
| سارة | مديرة المنتج | منظمة وحاسمة |
| عمر | مهندس برمجيات | هادئ، يحب التركيز، كثير القهوة |
| ليلى | مصممة واجهات | مبدعة وعفوية |
| حسن | مسوّق | اجتماعي ومتفائل |
| نور | محللة بيانات | دقيقة وتسأل أسئلة صعبة |
| علي | دعم العملاء | صبور ويحب المزاح |

## كيف يعمل
- كل بضع ثوانٍ يأخذ موظف دوره و"يفكر": يرى مكانه وطاقته ومزاجه وذاكرته وما قاله زملاؤه والمهام المفتوحة،
  ثم يقرر خطوته التالية (عمل / كلام مع زميل / استراحة / اجتماع / استلام مهمة / إنهاء مهمة).
- **مع مفتاح Claude**: كل قرار وكل جملة يكتبها Claude بشخصية الموظف (مخرجات JSON منظمة).
- **بدون مفتاح**: يعمل محرك سلوك محلي (وضع المحاكاة) حتى تجرب اللوحة فوراً.
- التحديث للمتصفح لحظي عبر Server-Sent Events.

## التشغيل
```bash
npm install
npm start                                  # وضع المحاكاة
ANTHROPIC_API_KEY=sk-ant-... npm start     # عقول Claude حقيقية
```
ثم افتح http://localhost:3000

### إعدادات اختيارية
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MODEL` | `claude-opus-5-5` | النموذج. لتقليل التكلفة كثيراً: `MODEL=claude-haiku-5-5` |
| `TICK_MS` | `4000` | الزمن بين كل قرار (ملّي ثانية) |
| `PORT` | `3000` | المنفذ |

> ملاحظة التكلفة: كل دورة = طلب واحد للـ API. بالافتراضي (4 ثوانٍ) هذا ≈ 900 طلب بالساعة.
> للتجربة الطويلة استخدم `claude-haiku-5-5` أو ارفع `TICK_MS`.

## من اللوحة تقدر

- ترسل إعلاناً للجميع ← يدخل ذاكرتهم ويتفاعلون معه.
