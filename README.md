# شركة فاي الافتراضية

شركة من موظفين ذكاء اصطناعي داخل Claude Code لخدمة [فاي](https://phi-iraq.org/)، مبنية حسب دليل nadr.ai "AI Company HQ".

- `CLAUDE.md`: تعليمات المدير التنفيذي (الجلسة الرئيسية).
- `team/`: دليل الشركة، الوصف الوظيفي، قوائم "تم"، المستويات، بروتوكول اللوحة، الروتين.
- `.claude/agents/`: الموظفون (IT، التطوير والحلول الذكية، التسويق).
- `board/index.html`: مصدر لوحة المكتب الحي: https://claude.ai/artifact/9eo5Wa8DgP9GhMVhCAZhs4
